# Daily Expense Tracker

A modular, menu-driven **C console application** designed to help users log, manage, and audit their daily expenditures. This project is structured specifically to align with standard academic computer science syllabi, covering fundamental concepts from basic programming flow to advanced system structures, memory manipulation, and persistence tracking.

## 🚀 Key Features

* **Complete Budget Enforcement:** Set a customized daily budget limit and receive automatic, calculation-backed threshold warnings whenever an added transaction breaches your target spending limit.
* **Persistent Binary Storage:** Transaction logs and preferences automatically serialize into a binary data stream (`expenses.dat`) and reload seamlessly on subsequent application boots.
* **Granular Analytical Searching:** Find specific items using linear category indices or utilize a manual, case-insensitive string parsing engine to pull text metrics from expense descriptions.
* **Dynamic Memory Escalation:** Allocates heap space efficiently using `calloc` and dynamically resizes arrays via an adaptive `realloc` system factor when data scale requirements grow.
* **Algorithmic Sorting Engine:** An integrated bubble-sort structure allowing immediate array re-ordering by gross amount (highest first) or custom calendar keys (chronological oldest first).
* **Automated Data Auditing:** Generates text-based balance metrics, highest/lowest margin highlights, average timeline trajectories, and category-focused distribution metrics mapped via text-symbol bar charts.

## 💾 Installation & Local Compilation

### Prerequisites
Ensure you have a C compiler such as `gcc` or `clang` configured inside your command-line environment pathway.

### Compilation
Open your terminal emulator, navigate directly to your local project directory path, and compile the script:

```bash
gcc daily_expense_tracker.c -o tracker
```

### Passing Custom Currencies
To override the default currency indicator (`Rs.`) at compile-time, feed an explicit macro variable directive directly to your compiler string:

```bash
gcc -DCURRENCY='"$"' daily_expense_tracker.c -o tracker
```

## 💻 Operational Run Guide

### Launch Default Tracker
Launches the tracking sequence utilizing the standard fallback ledger filename (`expenses.dat`):

```bash
./tracker
```

### Launch Targeted Data Logs
To load or create an alternate segregated storage database file, specify the filename target straight within your entry execution arguments:

```bash
./tracker business_2026.dat
```
